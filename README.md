# Personalized Study App

An AI-powered study platform that generates adaptive practice questions from your own learning materials.

## Overview

Upload your study resources — PDFs, slideshows, text notes, and more — and the app generates practice questions tailored to the content. As you answer, it tracks your performance and adapts in real time:

- **Struggling on a topic?** It revisits that area with more questions.
- **Mastering a concept?** It ramps up the difficulty.
- **Want 10 questions or 1,000?** You choose how many to generate.

The goal is to make studying more efficient by focusing your time where it matters most.

## Key Features (Planned)

- Upload and parse multiple resource types (PDF, PPTX, plain text, etc.)
- AI-generated questions that cover all topics in the uploaded material
- Adaptive question selection based on user performance
- Adjustable difficulty scaling
- Configurable session length (number of questions)
